# Alumni Connect Frontend

This repository contains the frontend code for the **Alumni Connect** platform, helping connect and engage alumni..

## Website
[Visit Alumni Connect](www.alumninehu.vercel.app)

## Project Description
Alumni Network is a platform where alumni can connect, share experiences, stay updated with events, and engage with their alma mater and fellow alumni.

## Technology Stack
- **React** with **Vite** for a fast and responsive UI
- **Tailwind CSS** for modern styling
- **React Router** for seamless navigation
- **Axios** for API integration
- **JWT** for session management

## Features
- Alumni registration and login
- Alumni profiles and network
- Event updates and announcements
- Responsive UI for mobile and desktop

## Setup Instructions
1. Clone the repo
2. Run `npm install`
3. Start development server with `npm run dev`
